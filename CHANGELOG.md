# Changelog

All notable changes to this project are documented in this file.

## [1.0.0] - 2026-08-12

Initial public research-software release.

- Added the Windows engineering workbench and checksummed three-member
  PEA-PGNN deployment ensemble.
- Added point prediction, key-age tables, reference-equation comparisons,
  batch CSV processing, input-support diagnostics, and CPU/CUDA inference.
- Added a protected formula library with read-only B3, GL2000, and ACI 209
  definitions.
- Added guided custom-formula editing, LaTeX/Unicode/calculator conversion,
  MathType MathML round trips, numerical trial calculation, and one-variable
  sensitivity screening.
- Added isolated user-formula storage, atomic writes, revision history,
  archive recovery, quarantine, and restricted expression evaluation.
- Added standard engineering and complete technical PDF calculation reports.
- Added automated tests and GitHub Actions for source, artifact, smoke, and
  report-generation checks.
